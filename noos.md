# NoOS

## Перед началом

- Убедитесь, что VNC/веб-консоль доступна.
- Запишите назначенные услуге IP и параметры сети.
- Не удаляйте основной IP и выполняйте действия по одному.

NoOS означает отсутствие установленной ОС. Добавить дополнительный IPv4 внутри системы пока невозможно. Установите выбранную ОС, учитывая, что установка или переустановка удаляет данные на диске, затем откройте её инструкцию в [оглавлении](SUMMARY.md). IP в панели сам по себе не подтверждает настройку внутри будущей ОС.
