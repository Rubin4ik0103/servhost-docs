# Дополнительный IPv4 для VPS/VDS

После покупки адрес может быть назначен услуге в панели, но не добавлен внутри ОС. Эта документация поможет добавить его к существующему интерфейсу, проверить входящие подключения и сохранить основной доступ. Настройка ОС выполняется клиентом самостоятельно.

## Перед началом

- Убедитесь, что доступна VNC или веб-консоль, и проверьте вход в неё.
- Сохраните резервную копию сетевой конфигурации своей ОС.
- Запишите адреса и маршруты: Linux `ip a`, `ip route`; FreeBSD `ifconfig -a`, `netstat -rn -f inet`; Windows `Get-NetIPAddress`, `Get-NetRoute`.
- Не удаляйте основной IP. Выполняйте действия по одному.
- Настройка внутри ОС выполняется клиентом самостоятельно. Держите текущую SSH/RDP-сессию открытой и проверяйте новую сессию отдельно.

> Настройка сети может прервать удалённый доступ. Если нет работающей консоли, сначала обеспечьте её доступность.

Для Linux-образа проверьте, что интерфейс действительно обслуживается `networking` и настроен в `/etc/network/interfaces` или подключённом файле. FreeBSD использует `/etc/rc.conf`, Windows - настройки адаптера.

Начните с [общей информации](general.md), выберите свою ОС через [оглавление](SUMMARY.md), затем при необходимости откройте [диагностику](troubleshooting.md) и [FAQ](faq.md). Значения адреса и префикса берите из параметров услуги; не подставляйте примерные числа.

> Переустановка ОС удаляет данные и может удалить сетевую настройку дополнительного IP. Перед переустановкой сохраните данные и конфигурацию.
